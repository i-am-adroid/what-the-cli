# what-the-cli 🤨

> A tiny CLI experiment where the README is allowed to be suspiciously self-aware.

**what-the-cli** is a playground for building command-line tools, experimenting with automation, and generally asking the important question:

**"what the CLI?"**

## Why does this exist?

Because sometimes you want a CLI that does something useful.

Sometimes you want to learn how CLIs work.

And sometimes you just want to make a repository called `what-the-cli`.

This project is for all three.

## Current status

🚧 **Experimental** — expect things to change.

The project may gain commands, configuration, automation, documentation, or completely unnecessary levels of polish over time.

## Philosophy

- Keep the interface simple.
- Make commands understandable.
- Prefer useful output over noise.
- Break things, learn why, fix them.
- If a feature can be explained in one sentence, start there.
- Most importantly: **have fun building it.**

## Getting started

Clone the repository and inspect what is here:

```bash
git clone https://github.com/i-am-adroid/what-the-cli.git
cd what-the-cli
```

Then build whatever comes next.
